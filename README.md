# Audio Output Toggle (Windhawk mod)

Press **Ctrl+Win+Up** to flip Windows' default sound output between two devices (for example Speaker and Headphone).
Music, games and calls all move together.

## Install

1. Install [Windhawk](https://windhawk.net/).
2. In Windhawk, click **Create a new mod**, replace the code with `audio-output-toggle.wh.cpp`, then **Compile Mod** and **Exit editing mode**.
3. In the mod's **Settings**, set the hotkey and part of each device's name as shown in Settings → System → Sound.

If the current output is the first device, the hotkey switches to the second. Otherwise it switches to the first.
